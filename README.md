# 🚀 Zajel — تطبيق زاجل للتوصيل السريع

تطبيق توصيل طلبات متكامل باللغة العربية (**RTL-Ready**) مبني بـ **Flutter**، مصمم لتجربة طلب سريعة وسلسة بدون تعقيد تسجيل الدخول (Guest-First Architecture).

## ✨ أبرز المميزات (Key Features)
- **واجهة عربية بالكامل (Full RTL UI):** تصميم عصري متجاوب بهوية بصرية مميزة (`#EC008C`).
- **تصفح الأقسام والمتاجر:** عرض منظم للأقسام (سوبر ماركت، صيدليات، خضار وفاكهة...) والأقسام الداخلية لكل متجر.
- **بحث ذكي (Smart Search):** اقتراحات الأكثر بحثاً، سجل البحث الأخير، وفلترة حسب التوفر.
- **سلة وحفظ محلي (Local-First Persistence):** حفظ السلة، الطلبات السابقة، وعنوان التوصيل تلقائياً على الجهاز باستخدام `SharedPreferences`.
- **إتمام طلب آمن (Production-Hardened Checkout):** التحقق من أرقام الهواتف المصرية، حماية ضد الضغط المزدوج، والدفع عند الاستلام.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework:** Flutter & Dart
- **State Management:** `ChangeNotifier` & `ListenableBuilder`
- **Local Storage:** `shared_preferences`
